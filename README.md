### 🔥 Qué hago

- **Sitios y plataformas a medida**: desde la arquitectura hasta producción, rápidos, accesibles y escalables.
- **Sistemas reutilizables**: headers con megamenú, catálogos con pedido por WhatsApp y librerías de páginas.
